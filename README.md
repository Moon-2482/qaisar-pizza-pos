# Qaisar Pizza POS 🍕

An **Android order-taking / POS app** built for a real pizza restaurant (Qaisar Pizza Club, Kuthiala Sheikhan, Pakistan) — orders, billing and daily records in one place.

## Features

- 🧾 Fast order-taking UI (Kotlin + WebView)
- 💾 Daily sales records with Google Drive backup (*khata* backup)
- 📊 Remote dashboard for the owner
- 🧹 One-tap data clear for a fresh day
- 🔄 **Self-updating** — the app checks `version.json` in this repo on startup and offers one-tap updates

## Install

Download the latest APK from the [**Releases**](https://github.com/Moon-2482/qaisar-pizza-pos/releases) page.

## Tech

Kotlin · Android WebView · Google Drive API

## Update channel

- `version.json` — latest `versionCode`, APK URL and changelog, checked by the app on startup
- Tagged releases carry the signed APKs
